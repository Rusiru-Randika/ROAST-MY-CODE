# 🔥 Roast My Code

> **"Your code has bugs. We have jokes."**

**Roast My Code** is an AI-powered code roasting and refactoring web application. Paste your code, choose your roast level (**🌶️ GENTLE**, **🔥 SAVAGE**, or **💀 NUCLEAR**), and get instant, humorous, and technically sharp developer feedback, issue identification, refactored code fixes, and downloadable pixel share cards.

---

## 🌟 Key Features

- **🔥 Humorous AI Roasts**: Entertaining developer humor analyzing code flaws without being abusive.
- **🌶️ 3 Roast Levels**:
  - **Gentle 🌶️**: Constructive feedback and friendly pointers.
  - **Savage 🔥**: Sharp, witty developer humor.
  - **Nuclear 💀**: Unfiltered, brutal engineering roasts.
- **🚨 Code Flaws & Problem Badges**: Clear breakdown of anti-patterns, security smells, and bad practices.
- **✨ Suggested Clean Refactoring**: 1-click refactored and idiomatic code suggestions.
- **📥 Downloadable Share Cards**: 1-click PNG image export and shareable social text cards.
- **📱 Fully Responsive**: Retro 80s arcade pixel design optimized for desktop and mobile devices.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/Rusiru-Randika/ROAST-MY-CODE.git
cd ROAST-MY-CODE
```

### 2. Install dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Create a `.env` file from the `.env.example` template:
```bash
cp .env.example .env
```
Add your Google Gemini API key:
```env
VITE_GEMINI_API_KEY=your_gemini_api_key_here
```

### 4. Run the development server
```bash
npm run dev
```
