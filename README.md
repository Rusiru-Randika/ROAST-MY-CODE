# 🔥 Roast My Code

> **"Your code has bugs. We have jokes."**

**Roast My Code** is an entertaining, creative AI-powered developer tool. Paste your source code, pick your roast intensity (Gentle 🌶️, Savage 🔥, or Nuclear 💀), and get a hilarious developer roast coupled with actionable technical feedback, bug identification, and refactored code powered by AI.

---

## 🌟 Key Features

- **🔥 Humorous & Playful AI Roasts**: Entertaining developer humor that highlights anti-patterns without being personal or abusive.
- **🌶️ 3 Roast Levels**:
  - **Gentle 🌶️**: Friendly jokes and constructive pointers.
  - **Savage 🔥**: Sharp, snarky developer humor (default).
  - **Nuclear 💀**: Unfiltered senior engineer brutal honesty.
- **🧠 Deep Technical Analysis**: Accurate explanations of real code anti-patterns, cyclomatic complexity, security risks, and semantic issues.
- **🚨 Categorized Issues & Scores**: Severity gauge (1-10) with HIGH/MEDIUM/LOW issue badges.
- **✨ Suggested Refactored Code**: 1-click clean code replacement with copy functionality.
- **📋 Copy & 📸 Social Share Cards**: Visually rich share cards formatted for social media or team chats.
- **⚡ 1-Click Code Examples**: Instant load buttons for Python 🐍, JavaScript ⚡, Java ☕, SQL 🗄️, and HTML 🌐.

## 🚀 Quick Start & Local Development

### Prerequisites
- Node.js 18+ & `npm`

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/roast-my-code.git
   cd roast-my-code
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```

4. Open your browser at `http://localhost:5173`.
